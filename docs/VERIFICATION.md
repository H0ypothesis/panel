## 浏览器验收

在 Codex 内置浏览器中实际操作：

1. 打开示例图，选择节点并查看完整回答。
2. 新建独立探索，提交两条根分支，观察二者同时处于“生成中”。
3. 第一条使用“深入”、第二条使用“标准”，节点保存各自配置。
4. 单独停止第三条分支，保留其取消状态，其余分支完成。
5. 查看第一条分支上下文，只有根与该分支，没有第二、第三条内容。
6. 在第一条下新建深层分支，运行中刷新，刷新后继续显示并最终完成；Pi 收到两条祖先用户消息。
7. 搜索第二条分支，选择结果后定位到画布并同步详情。
8. 验证 JSON / Markdown 导出入口与本地模型连接配置指引。
9. 在 960 × 760 窗口验证图与详情面板、导航抽屉、连接设置和搜索；恢复默认窗口后继续操作。

没有浏览器运行错误。开发热更新曾产生 React Flow 的 nodeTypes 变更提示，初始生产构建中 nodeTypes 定义在组件外部。
