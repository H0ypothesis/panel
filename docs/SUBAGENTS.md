# Subagents 子代理协作

Panel 接入 [nicobailon/pi-subagents](https://github.com/nicobailon/pi-subagents) `0.73.1`，复用它的前台执行引擎。无需另装 Pi CLI 或重复配置模型。

## 使用

- **自动委派**：真实模型始终可以调用 `subagent`，根据系统指令决定是否拆分任务；简单任务可以直接回答。
- **明确要求协作**：在输入框输入 `@`，选择 **Subagents**。本轮先调用 `subagents_enable` 开启能力，再指示主模型实际委派有用的子任务。启用记录与真实子代理运行分开显示；仅输入普通文本 `@subagents` 不等同于选择菜单项。
- **查看结果**：创建子代理后，原卡片出现角色头像和完成数量；点击头像打开右侧 **Subagents** 子页。子页列出全部代理，可切换查看任务、模型、思考、回答、用量和工具审批。对话详情保留主代理的综合回答。
- **停止**：停止原卡片会取消这轮运行中、排队中以及等待审批的子代理。刷新保留状态；服务重启或导入 JSON 会将未完成的代理标记为已停止，不自动重放。

## 角色和执行边界

| 角色       | 工作               | 工具                               |
| ---------- | ------------------ | ---------------------------------- |
| `scout`    | 调查指定文件或网页 | `read`、`web_search`、`web_fetch`  |
| `worker`   | 实现、分析与验证   | 上述工具及 `write`、`edit`、`bash` |
| `reviewer` | 独立审查指定内容   | `read`、`web_search`、`web_fetch`  |

子代理使用本轮相同的模型、思考深度和模型连接快照，拥有独立上下文。主模型需要在委派任务中提供文件路径、目标和必要背景；父对话历史与附件不会自动复制给子代理。父模型收到每个子代理的结果后综合回答。

一次 `subagent` 调用可传入单个 `agent` / `task`，或 `tasks` 列表。每批最多 8 个，同一时间最多执行 3 个，每轮最多 24 个。每个子代理最多运行 30 分钟，受正常模型轮次上限约束；本轮开启长程任务时沿用长程设置。

所有子代理共享本卡片工作目录，文件工具仍通过 Panel 的目录约束、操作协调和 Git 快照。委派和开启能力按策略执行；具体文件、命令和联网操作沿用当前人工批准或安全模型审核，委派不替代审批。子代理用量计入卡片总用量。子代理不继续创建子代理，也不开放电脑控制工具。

## 维护

适配入口为 `server/nicobailon-engine.ts`，通过上游的逐次 `ChildSessionFactory` 接口接入 Panel runtime；不修改全局工厂、不使用外部 `pi` 进程。版本精确锁定，因为前台执行入口是内部模块。升级需运行子代理集成测试及桌面冒烟测试。

这次接入同步单任务与并行批次、流式状态、取消和结果汇总。上游 CLI/TUI 管理器、后台脱离、链式模板、远端 runner、自定义 agent 文件及嵌套委派不在当前界面支持范围内。依赖所需的 SDK/TUI 保留为固定版本；Panel 自己承载子会话和界面。
