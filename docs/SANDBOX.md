# 编码沙盒

[工具与审批](TOOLS.md)

Panel 复用 Pi 的原生编码工具和官方 `@anthropic-ai/sandbox-runtime`，结合插件方案的文件保护、目标授权与执行记录。沙盒策略由宿主提供，模型参数不能关闭它。初始化失败后先恢复，仍失败时暂停原命令，绝不自动退回宿主权限执行。

## 初始化与恢复

- 主代理和子代理开始时预检查依赖、文件策略和代理初始化，不执行测试命令。每条命令仍独立初始化自己的沙盒。
- 进程退出、初始化超时等临时故障清理后自动重建一次；缺少依赖、系统不支持不会反复重试。单次初始化最多等待 15 秒。
- 仍失败时显示原命令、真实工作目录、失败原因及尝试次数。可以选择「重试沙盒」「仅本次在宿主执行」或拒绝。重试成功会修复本轮预检查状态，后续命令继续使用沙盒。
- 宿主执行始终需要人工确认，包括自动审批模式。选择绑定原命令、目录、卡片及子代理、审批配置和一次执行；不能批量批准，不沿用网络授权，不授权下一条命令。宿主执行记录会明确标注，不显示为沙盒内执行。
- 取消、文件策略拒绝、目录真实路径改变，以及用户命令开始后的错误、网络或文件权限拒绝，都不会进入宿主恢复，也不会自动重放已经执行的步骤。恢复等待发生在命令超时计时之前，可以取消。

单次宿主执行保留环境变量过滤、私有临时目录、输出记录、取消和项目 Git 快照，但失去原沙盒的文件及网络限制。宿主命令可以影响项目外文件；这些变化不在项目 Git 快照的恢复范围内。模型不能主动调用恢复能力或要求换一条命令。

## 执行与授权

- Panel 提供的 `read`、`write`、`edit`、`bash` 在两种审批模式下都直接执行，并保留参数审计、单次授权消费、取消和 Git 快照。
- 文件工具限制到项目真实路径；命令及后代进程写入限于当前项目和每条命令的私有临时目录。
- 默认保护 `.env*`、密钥文件、常见宿主凭证目录、Panel 状态及 Git/工具执行配置。子代理 `.pi/subagents/artifacts` 产物及 `.pi/subagents/handoffs` 交接目录保留读写权限。
- 命令第一次访问一个域名和端口时产生 `sandbox_network` 请求。请求批准模式由用户确认，自动模式由所选安全模型审核；同一卡片本轮、同一目录的相同目标复用授权。
- 授权不跨目标、轮次、重启或审批设置变化延续；禁止批量批准全部联网目标。批准后原命令继续执行，不重新运行之前的步骤。
- 主代理和 Pi 子代理的编码工具共用执行器。命令使用独立管理进程，避免并行卡片互相覆盖沙盒策略；完成或取消后回收代理与私有临时目录。

## 影响与边界

macOS 使用 `sandbox-exec`；Linux 使用 Bubblewrap，需要可用的 `bwrap`、`socat` 和 `rg`。Windows 尚未接入沙盒，命令会进入人工恢复选择。桌面包随附沙盒运行时和执行器。

命令读取除受保护区域外的本机文件仍可能被允许，因此这不是完整虚拟机或容器。项目内的删除、覆盖等操作也会直接执行；沙盒不提供分支文件隔离，文件共享和 Git 快照规则继续有效。

联网只能通过沙盒代理，禁止绕过代理、访问本机/内网和使用宿主 Unix socket；默认不允许本地监听，依赖本地端口的开发预览或测试会受到影响。需要宿主全局缓存或凭证的工具也可能失败，应使用项目目录或私有临时目录。

目标授权允许该域名和端口的网络连接，代理不能区分同一目标上的读取、上传或远端修改；批准时应考虑本轮用途。文件边界继续生效。电脑控制、联网插件和外部 CLI 扩展使用原审批规则，不因命令沙盒而自动放行，也不在此命令沙盒的隔离范围内。

命令执行中的联网批准等待计入超时（默认 120 秒，最多 600 秒）。执行前的普通工具审核仍沿用原有调度规则。
